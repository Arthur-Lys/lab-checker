# lab-checker

https://lab-checker-six.vercel.app

Форма для перевірки лабораторних на `laboratory-checker-actions.onrender.com`. Сторінка робить `fetch()` на той
самий `/quiz/start`, що й сайт викладача, через маленький проксі (`api/submit.py`), і показує відповідь.

## Що змінив

- форма не скидається після відправки, поля і результати лишаються в localStorage
- можна вибрати кілька лабораторних, вони йдуть по черзі
- під кожною відповіддю — коротке пояснення, повний текст під спойлером
- ім'я перевіряється у списку сервера, поки друкуєш (через 0,5 с після паузи)
- вставлене посилання на GitHub само стає `user/repo`
- група і предмет — зі списку, який приймає сервер

## Що не так із сервером перевірки (15.09.2026)

1. **Lab_01, `CONTENT_VARIANT_MISMATCH` на будь-який звіт.** Номер варіанта читається правильно
   (звіт із «Варіант №6» → «Варіант у звіті: 6»), а зміст відхиляється завжди. Пробував: справжній звіт (docx і pdf),
   docx лише з текстом варіанта 1 з методички, docx з усією методичкою, те саме pdf, код з функціями з прикладу
   (`calculate_group_average`, `find_best_student`, `filter_by_group`), варіант 1 у двох студентів і варіант 6 у третього.
   Десять спроб, одна відповідь: «недостатньо змістових ознак».
2. **Lab_02–Lab_10 — HTTP 500**: `Rules for course 'professional_python', laboratory 'Lab_02' were not found.
   Expected module: rules.professional_python.lab02`. Правил нема, перевірити не може ніхто.
3. Студент бачить сирі винятки Python зі шляхами (`/tmp/tmp02z0ziq7/student`, `students.json`).
4. Неіснуючий репозиторій — 500 з `fatal: could not read Username for 'https://github.com'` замість «не знайдено».
5. Форма очищається після кожної відправки, а відправка триває 5–30 с.
6. Render засинає: перший запит після паузи — 30 с+.

## Помилки, які отримував, поки заливав лабораторні

| Відповідь | HTTP | Причина |
|---|---|---|
| `FileNotFoundError: У GitHub repository не знайдено каталог Lab_01` | 500 | у корені потрібен каталог `Lab_01` |
| `REPORT_NOT_FOUND` | 403 | у назві звіту має бути `report`, `zvit` або `звіт`; `Lab_01_Лис.docx` не підходить |
| `RuntimeError: Знайдено декілька можливих звітів` | 500 | такий файл має бути один |
| `VARIANT_MISMATCH` (призначений 6, у звіті 1) | 403 | номер на титулці не той, що в таблиці викладача |
| `CONTENT_VARIANT_MISMATCH` | 403 | пункт 1 вище |
| `ValueError: Студента не знайдено у students.json` | 400 | ім'я не як у списку |
| `Не заповнені всі необхідні поля.` | 400 | порожнє поле |
| `RuntimeError: Не вдалося клонувати GitHub repository` | 500 | помилка в `user/repo` або приватний репозиторій |
| `ValueError: Rules for course ... were not found` | 500 | пункт 2 вище |
