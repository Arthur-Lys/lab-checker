# Lab checker — інша форма для того самого сервера перевірки

Сайт: **https://lab-checker-six.vercel.app**

Це не своя перевірка. Кожен запит іде на `laboratory-checker-actions.onrender.com/quiz/start` — той самий сервер,
що й на сайті викладача. Ця сторінка лише інакше подає форму й пояснює відповіді.

- `index.html` — сторінка (React з CDN, без збірки)
- `api/submit.py` — функція Vercel, яка пересилає одну відправку на сервер і повертає текст відповіді без HTML

## Що зроблено інакше

| На сайті викладача | Тут |
|---|---|
| Форма очищається після кожної відправки | Поля зберігаються в браузері (localStorage), разом з останніми результатами |
| Одна лабораторна за раз | Будь-який набір лабораторних одним натисканням, по черзі |
| Помилка — сирий текст винятку Python | Кожна відповідь отримує пояснення людською мовою і повний текст під спойлером |
| Ім'я перевіряється лише після відправки | Ім'я перевіряється у списку сервера, поки ти друкуєш (через 0,5 с після паузи) |
| Посилання на GitHub треба вручну скоротити до `user/repo` | Вставлене посилання скорочується автоматично, формат перевіряється до відправки |
| Група вводиться руками | Група і предмет — зі списку, який приймає сервер |

## Проблеми сервера перевірки, знайдені 15.09.2026

Усе нижче відтворено через звичайну форму відправки, з публічним репозиторієм `ArturLys/python-labs`.

1. **`CONTENT_VARIANT_MISMATCH` для будь-якого звіту, Lab_01.** Перевірка номера варіанта працює (звіт із
   «Варіант №6» дає «Варіант у звіті: 6»), а перевірка змісту відхиляє все, що ми пробували:
   - справжній звіт (docx і pdf);
   - docx, у якому лише текст варіанта 1 з методички і приклад коду з неї;
   - docx з повним текстом методички Lab_01 (усі 15 варіантів);
   - те саме як pdf;
   - код у репозиторії з функціями з прикладу (`calculate_group_average`, `find_best_student`, `filter_by_group`, `find_student`);
   - варіант 1 для двох різних студентів і варіант 6 для третього.
   Усі десять спроб — та сама відповідь: «У звіті знайдено недостатньо змістових ознак призначеного варіанта».
2. **Lab_02–Lab_10 — HTTP 500.** `ValueError: Rules for course 'professional_python', laboratory 'Lab_02' were not found.
   Expected module: rules.professional_python.lab02`. Правил для цих лабораторних на сервері нема, перевірити їх
   не може ніхто.
3. **Сирі винятки Python показуються студентові**, з внутрішніми шляхами модулів (`rules.professional_python.lab02`,
   `/tmp/tmp02z0ziq7/student`, `students.json`).
4. **Форма скидається** після кожної відправки, а сама перевірка триває 5–30 с.
5. **Неіснуючий репозиторій дає 500, а не 400**: `fatal: could not read Username for 'https://github.com'` — git
   намагається спитати пароль замість зрозумілого «репозиторій не знайдено».
6. Сервер на безкоштовному Render засинає: перший запит після паузи — 30 с і більше.

## Що ми отримували при завантаженні лабораторних

| Відповідь сервера | HTTP | Що означає |
|---|---|---|
| `FileNotFoundError: У GitHub repository не знайдено каталог Lab_01` | 500 | У корені репозиторію потрібен каталог `Lab_01` (нуль, підкреслення) |
| `REPORT_NOT_FOUND` | 403 | Потрібен pdf або docx, у назві якого є `report`, `zvit` або `звіт`; `Lab_01_Лис.docx` не підходить, `Lab_01_report.pdf` — так |
| `RuntimeError: Знайдено декілька можливих звітів: [...]` | 500 | Таких файлів має бути рівно один |
| `VARIANT_MISMATCH` (Призначений варіант: 6, Варіант у звіті: 1) | 403 | Номер на титулці не збігається з варіантом студента в таблиці викладача |
| `CONTENT_VARIANT_MISMATCH` | 403 | Див. пункт 1 вище — відповідь на будь-який зміст |
| `ValueError: Студента не знайдено у students.json` | 400 | Ім'я не так, як у списку («Прізвище Ім'я», кирилиця) |
| `ValueError: Група %D4%E5%CF-31 не належить курсу` | 400 | Групу надіслано не в UTF-8 (це наш curl з Windows, не сайт) |
| `Не заповнені всі необхідні поля.` | 400 | Порожнє поле |
| `RuntimeError: Не вдалося клонувати GitHub repository` | 500 | Помилка в назві `user/repo` або приватний репозиторій |
| `ValueError: Rules for course ... were not found` | 500 | Правил для лабораторної на сервері нема |
